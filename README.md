# LED-LDR

🇧🇷 Exercício de eletrônica/Arduino: um sensor LDR (fotoresistor) lê o nível de luz ambiente e aciona um LED automaticamente quando escurece — um circuito clássico de acionamento por luminosidade.

🇬🇧 Arduino/electronics exercise: an LDR (light-dependent resistor) sensor reads ambient light and automatically switches a LED on when it gets dark — a classic light-triggered switch circuit.

**Stack:** Arduino (C/C++)
