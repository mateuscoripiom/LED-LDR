# LED-LDR

🇧🇷 Exercício de eletrônica/Arduino: um sensor LDR (fotoresistor) no pino analogico A0 e lido continuamente; quando o nivel de luz cai abaixo de um limiar, dois pinos digitais são acionados -- um circuito clássico de acionamento automático por luminosidade (ex: luz noturna).

🇬🇧 Arduino/electronics exercise: an LDR (light-dependent resistor) on analog pin A0 is read continuously; when the light level drops below a threshold, two digital pins are switched on -- a classic light-triggered automatic switch circuit (e.g. a night light).

**Stack:** Arduino (C/C++)
**Contexto:** provável exercício da época técnica (ETEC, 2021-2023).
